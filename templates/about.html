Ancient Sinhala Script Recognition System

This application uses a Convolutional Neural Network to classify Ancient Sinhala script images into different historical eras.

How It Works

01

Upload

User uploads a Sinhala script image.

02

Preprocess

Image is converted to grayscale and resized to 64×64.

03

CNN Prediction

The trained CNN predicts the historical era.

04

Result

System displays the predicted era and confidence.

Model Information

Architecture

Convolutional Neural Network

Input

64 × 64 × 1

Output

5 Classes

Framework

TensorFlow / Keras
