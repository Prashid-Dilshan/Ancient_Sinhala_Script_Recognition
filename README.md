# 🏛️ Ancient Sinhala Script Recognition AI

An AI-powered web application for recognizing and classifying Ancient Sinhala script images into different historical eras using a Convolutional Neural Network (CNN).

The system allows users to upload an inscription image, preprocesses the image automatically, passes it through a trained CNN model, and displays the predicted historical era together with its confidence score and class probability breakdown.

---

## 📌 Project Overview

Ancient Sinhala inscriptions are important sources for understanding the history and development of the Sinhala writing system.

This project uses Deep Learning and Computer Vision to build an image classification system capable of recognizing Sinhala script styles from different historical periods.

The application provides a simple web interface where users can:

- Upload an inscription image
- Preview the selected image
- Run AI-based script recognition
- View the predicted historical era
- View prediction confidence
- View probability for all supported classes
- Receive a warning for low-confidence predictions
- Learn about the predicted historical era
- Save predictions automatically
- Search previous predictions
- Filter prediction history by era
- View detailed prediction information
- Delete previous prediction records

---

## 🚀 Features

### 🔍 Script Recognition

Upload an image of a Sinhala inscription and let the trained CNN model predict its historical script era.

### 🖼️ Image Upload

The application supports:

- JPG
- JPEG
- PNG
- WEBP

Maximum upload size : 5 MB
